# Web Console 設計規範

既有藍白識別延續，主要工作順序為「選擇影像 → 檢視證據 → 分析 → 匯出」。不得以裝飾、帳號資訊或進階設定壓過影像與結果。

## 結構與密度

- 首頁突出單張／批次偵測，之後是最近工作；其他功能採次要連結。
- AI 功能共用「AI 助理」入口，頁內以「一般對話／偵測分析」連結分頁切換；保留獨立頁面與 service。分析頁即使收合設定也顯示目前分析資料。
- 一般頁首只顯示標題與必要說明；不重複使用大面積 hero 或英文 kicker。
- 偵測工作區分設定與原圖／標註圖。全域與各類別閾值放在進階設定，預設值及功能保留。
- 偵測頁在 1100px 以上並排時，設定、原圖與結果卡片等高；較窄尺寸回到自然高度及堆疊，避免手機產生大面積空白。
- YOLO 選單用原生 optgroup 區分類別數、Pre、OBB 與 COCO；選項顯示架構短名，下方顯示可換行的完整模型名稱。分類使用 API metadata，Pre 保留原命名，不推斷其訓練意義。
- 進階閾值摘要的標題與數值固定分行；conf、IoU 各自保持名稱及數值完整，空間不足時以整組換行。
- 一般資料使用邊框區分表面；避免每個內容群組都加入陰影。
- 以 `--space-section`（28px）區隔工作群組，群組內用 16px；手機保留 16–20px 邊距。

## 字體與顏色

- 字體沿用 Segoe UI、PingFang TC、Microsoft JhengHei，不新增外部字型。
- 頁標題約 1.65–2rem，區塊標題 1.125–1.25rem，內文 1rem；次要資料約 .8125rem。
- 使用 `--text`、`--muted`、`--accent`、`--accent-strong` 及狀態 tokens；淡色表面上的連結用 accent-strong，刪除用 danger-text。
- 數字資料採 tabular numerals。標籤和值分行呈現，長檔名／Email 可換行。

## 響應式與互動

- 1100px 以下導覽收合；900px 以下 Chat 清單／對話切換、分析設定可收合；600px 以下影像比較與表單改為單欄。
- 控制項至少 44px 觸控高度；所有欄位保留名稱與鍵盤焦點提示。
- Modal 使用共用原生 dialog。Escape、背景 inert、焦點隔離與關閉後返回觸發器為必要行為。
- 模型使用原生 select；圖片支援縮放、方向鍵平移及 Escape 關閉。
- 等待、錯誤、空資料與成功都要有文字；串流完成才公告，避免逐 token 播報。
- AI 分頁切換保留各自草稿、目前對話、模型及分析資料；僅保留於工作區記憶體，離開工作區、重新整理或登出清除。生成途中切換停止前端接收並標明不完整回覆，不能宣稱取消後端作業。
- 旋轉等待提示使用 CSS 動畫；reduced-motion 下保留靜態狀態指示。

## 實作界線

保持 `/chat` 與 `/agent` 的頁面及 service 獨立，沿用共用 Axios。結果選擇器只能讀取既有偵測，不重新執行 YOLO。不得引入 UI framework 或改動 Desktop。
