# Web Console 設計規範

既有藍白識別延續，主要工作順序為「選擇影像 → 檢視證據 → 分析 → 匯出」。不得以裝飾、帳號資訊或進階設定壓過影像與結果。

## 結構與密度

- 工作台突出單張／批次偵測。「查看偵測紀錄」是區塊層級的次要入口，最近工作每筆以整列連結開啟，列尾顯示「繼續分析」或「查看進度」。其他功能使用一致的圖示、名稱與導覽箭頭。
- AI 助理以同一個工作區容納「一般對話／偵測分析」。頁首與操作列保持精簡，輸入區固定在工作區底部，回覆區獨立捲動並取得剩餘高度。桌面可收合歷史或分析設定，分析頁的當前模式與資料顯示在回覆上方。
- 一般頁首只顯示標題與必要說明；不重複使用大面積 hero 或英文 kicker。
- 偵測工作區分設定與原圖／標註圖。全域與各類別閾值放在進階設定，預設值及功能保留。
- 偵測頁在 1100px 以上並排時，設定、原圖與結果卡片等高；較窄尺寸回到自然高度及堆疊，避免手機產生大面積空白。
- YOLO 選單區分類別數、Pre、OBB 與 COCO，可搜尋模型名稱、類別或分組。收合時分行顯示架構和分組，下方顯示完整模型名稱與可偵測類別（超過 12 類先收合）。分類使用 API metadata，Pre 保留原命名。
- 0 物件結果列出該模型類別，提供改用 COCO 重試與調低信心閾值；換模型保留上次結果並標示需重新偵測。完成時公告結果，焦點仍在送出鈕時移到結果標題。
- 進階閾值摘要的標題與數值固定分行；conf、IoU 各自保持名稱及數值完整，空間不足時以整組換行。
- 一般資料使用邊框區分表面；避免每個內容群組都加入陰影。
- 以 `--space-section`（28px）區隔工作群組，群組內用 16px；手機保留 16–20px 邊距。

## 字體與顏色

- 字體沿用 Segoe UI、PingFang TC、Microsoft JhengHei，不新增外部字型。
- 頁標題約 1.65–2rem，區塊標題 1.125–1.25rem，內文 1rem；次要資料約 .8125rem。
- 使用 `--text`、`--muted`、`--accent`、`--accent-strong` 及狀態 tokens；淡色表面上的連結用 accent-strong，刪除用 danger-text。
- 數字資料採 tabular numerals。標籤和值分行呈現，長檔名／Email 可換行。

## 響應式與互動

- 1100px 以下網站導覽收合。AI 助理在 900px 以下一次顯示對話、歷史或分析設定，切換時將焦點交到目前操作的區域。600px 以下影像比較與偵測表單改為單欄。
- 控制項至少 44px 觸控高度；所有欄位保留名稱與鍵盤焦點提示。
- Modal 使用共用原生 dialog。Escape、背景 inert、焦點隔離與關閉後返回觸發器為必要行為；需指定初始焦點時用 `initialFocusRef`。
- 刪除一律用共用 `ConfirmDialog`：標題寫明對象，內文寫明連帶刪除的內容，預設焦點在取消，處理中保持開啟並在框內顯示錯誤。不使用列內／行內確認。
- 介面文案統一繁體中文；API 狀態與類型經 `utils/labels.js` 轉為中文，模型名稱經 `useYoloModelName` 顯示 registry 的 display name（provenance 晶片保留 `model_key` 與 SHA）。
- 單選欄位共用 `SelectField`。推論模型與已保存結果使用可搜尋面板，AI 模型按供應商分組並直接列出選項，短篩選和分析模式也直接列出選項。清單以勾號標示已選項、文字說明不可用項；已套用的紀錄篩選以淡藍底與選取文字提示。鍵盤可用方向鍵瀏覽、Enter 選取、Escape 取消並回到欄位。不支援 Popover API 時使用原生 select。
- 圖片支援縮放、方向鍵平移及 Escape 關閉。
- 等待、錯誤、空資料與成功都要有文字；串流完成才公告，避免逐 token 播報。
- AI 分頁切換保留各自草稿、目前對話、模型及分析資料；僅保留於工作區記憶體，離開工作區、重新整理或登出清除。生成途中切換停止前端接收並標明不完整回覆，不能宣稱取消後端作業。
- 歷史標題篩選僅用一般對話載入的最近 100 則。手動開啟歷史從第一則開始，靠近底部時才跟隨新回覆，上捲可用「回到最新」返回。回覆中的長程式碼與寬表格在區塊內捲動。
- 旋轉等待提示使用 CSS 動畫；reduced-motion 下保留靜態狀態指示。

## 實作界線

保持 `/chat` 與 `/agent` 的頁面及 service 獨立，沿用共用 Axios。結果選擇器只能讀取既有偵測，不重新執行 YOLO。不得引入 UI framework 或改動 Desktop。
